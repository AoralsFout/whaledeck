# IPC 契约

> 本文是前端与 Rust 之间**命令名、参数、返回值、错误与事件**的唯一权威。
> 命令的内部算法见 [后端实现.md](后端实现.md)；数据形状见 [数据模型.md](数据模型.md)。

---

## 1. 调用约定

- 传输：Tauri 2 `invoke` / `listen`；前端统一封装在 `src/lib/ipc.ts` 的 `api` 对象。
- 参数名：JS 侧使用 camelCase（如 `gameId`），Tauri 自动映射到 Rust 的 snake_case 参数。
- 结构体字段：两侧都是 camelCase（Rust `#[serde(rename_all = "camelCase")]`）。
- 错误：Rust `Result<T, String>` 失败时 Promise reject，`String(err)` 即中文错误文案；前端不解析错误码。
- 取消：文件/保存对话框返回 `null`；`export_library` 返回 `false`；`import_library` 返回 `0`。
- 前端不得直接 `invoke("...")` 或拼接命令名；新增命令必须同时更新 `api`、本文件与 [后端实现.md](后端实现.md)。

## 2. 命令总表

### 2.1 游戏库

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `list_games` | — | `Game[]` | 读取内存中的游戏库（启动时已从磁盘载入） |
| `save_game` | `game: Game` | `Game` | 新增或按 `id` 更新；返回后端确认后的完整记录 |
| `save_cover_framing` | `id: string`、`framing: CoverFraming` | `Game` | 只更新取景；校验位置/缩放有限且在有效范围，封面文件必须仍与当前记录匹配；先写盘再更新内存，失败保留原效果 |
| `delete_game` | `id: string` | `boolean` | 移除记录；不存在返回 `false`；运行中报错 |
| `reset_playtime` | `id: string`、`sec: number` | `Game` | 覆盖累计时长（秒），返回快照 |

`save_game` 行为要点：


- `title` / `exePath` 为空 → 报错。
- `id` 为空 → 生成 UUID v4；`addedAt` 为 0 → 写入当前毫秒。
- `savePaths` 去空白、丢空项。
- 先写盘成功，再替换内存；失败时原列表不变。

### 2.2 启动与计时

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `launch_game` | `id: string` | `LaunchResult` | 启动目标；进程目标创建会话并开始监控 |
| `get_sessions` | — | `Session[]` | 当前运行中的会话 |

`launch_game` 行为要点：

- 记录不存在 → 报错；同一 `gameId` 已在运行 → 报错。
- 启动失败：广播 `launch-failed` 并 reject。
- `pid === null`：用系统默认程序打开，不创建会话、不计时；仍更新 `lastPlayedAt`。
- `pid !== null`：写 `pending_session.json`、启动监控线程、更新 `lastPlayedAt`。

### 2.5 资源

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `import_cover` | `id: string`、`src: string` | `string` | 复制独立草稿图片到 `covers/`，返回文件名；ID 校验同 `import_icon`，支持 PNG、JPG、JPEG、WebP、GIF、BMP；不改记录 |
| `import_icon` | `id: string`、`src: string` | `string` | 复制图标到 `icons/`，返回文件名；支持 `pick_image` 的图标格式；ID 仅允许 ASCII 字母、数字、连字符与下划线且非空；失败返回中文错误，不改记录 |
| `import_background` | `src: string`、`target?: "main" \| "sidebar"` | `string` | 复制到 `backgrounds/`，同时保存对应背景引用，返回唯一文件名；省略 target 等同 main；失败保留原背景 |
| `asset_path` | `kind: "cover" \| "background" \| "icon" \| "superres" \| "backgroundFit"`、`file: string` | `string` | 返回绝对路径；前端再经 `convertFileSrc` 展示 |

### 2.5.1 侧栏背景适配

`fit_sidebar_background({ request }) -> BackgroundFitResult`：异步后台处理，不保存设置。request 为 `{ sourceKind: "cover" | "background", file: string, width: number, height: number, padding: number, mode: "contain" | "cover" | "stretch", positionX: number, positionY: number }`，尺寸与扩边均为物理像素。仅允许指定资源目录内的文件名。

结果为 `{ file, sourceWidth, sourceHeight, width, height, padding, cacheHit }`；`asset_path` 新增 `kind: "backgroundFit"` 解析派生图。错误不改原图或设置。请求限制与缓存实现见后端文档；前端封装为 `api.fitSidebarBackground`。

### 2.9 联网补全

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `search_meta` | `source: "bangumi" \| "vndb" \| "ymgal"`、`keyword: string` | `MetaItem[]` | 异步；联网检索 |
| `apply_meta` | `gameId: string`、`item: MetaItem` | `Game` | 下载封面并更新非空字段与来源 |
| `autofill` | `game: Game`、`field?: AutofillField \| null` | `AutofillResult` | 基于当前草稿生成本地候选，不写游戏库；省略 field 获取全部 |

`apply_meta` 行为要点：

- 有 `coverUrl` 时才下载；域名白名单、12MB 上限。
- 下载新封面后清除旧取景；没有下载封面时保留取景。独立文件与存储行为见数据模型及后端实现。
- 只写入非空的 `summary` / `developer` / `releaseDate`；`source` / `sourceId` 总是写入。
- 返回更新后的完整 `Game`，前端据此替换记录。

`autofill` 行为要点：

- 版本资源读不到时跳过，不影响图标/封面。
- 仅获取所选字段；名称、开发商、备注有非空候选即覆盖返回草稿的对应值，没有则保持输入值；图像结果写入独立资源文件，不覆盖或清理原资源。
- `filled` 是本次获取到的中文文本字段名（如 `["名称","开发商","备注"]`），`icon` / `cover` 表示图像候选是否生成；字段枚举见 [数据模型.md](数据模型.md) §2.5。
- 输入目标路径为空或不存在时返回可展示错误；允许未加入游戏库的新增草稿。确认后仍通过 `save_game` 保存。

### 2.10 封面超分

| 命令 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `superres_status` | `id: string, preset?: "efficient" \| "quality"` | `string \| null` | 查询指定档缓存；省略档位兼容效率档；非法档位报错 |
| `superres_generate` | `id: string, preset?: "efficient" \| "quality", taskId?: string` | `string \| null` | 命中有效缓存直接返回；否则启动后台任务；调用者可指定 UUID 任务标识，省略时后端生成 |
| `superres_task` | `id: string` | `SuperResProgress \| null` | 查询该游戏当前任务（含标识、档位、阶段和已用时间），挂载后用于恢复进度 |
| `superres_cancel` | `id: string, taskId?: string` | `boolean` | 请求取消；命中当前任务返回 `true`；真正终止由工作线程执行 |
| `superres_remove` | `id: string` | `void` | 删除该游戏的全部派生图，恢复显示原图 |

行为要点：

- 所有超分事件携带 `preset`、唯一 `taskId`。前端按标识隔离迟到的终态、取消和命令响应；取消指定任务时不会影响同一游戏的新任务。订阅后查询任务快照，快照不得覆盖更新的事件。完成事件显示前须重查当前封面缓存，丢弃旧封面结果。任务槽释放后发送终态事件。删除时若该游戏仍在处理则报错。

- 档位模型与参数见 [后端实现.md](后端实现.md) §8.5；两档本机处理，原封面不覆盖。
- 同一时刻只跑一个任务；已有任务时 `superres_generate` 返回中文错误，不排队。
- 缓存必须可完整解码为 PNG 才命中；损坏结果可重新生成。游戏 ID 限非空 ASCII 字母、数字、连字符与下划线；封面资源引用必须是单层文件名。
- 缓存键及布局见 [数据模型.md](数据模型.md) §3；两档缓存隔离，原图内容变化自然失效。
- 先写同名 `.tmp.png`，成功后原子改名；失败、取消都删除临时文件，工作进程随任务结束退出。
- 没有可靠计数，进度只有 `processing` / `resizing` / `saving` 阶段与已用时间，不伪造总百分比。
- 无封面、封面文件丢失、辅助程序或模型缺失，均返回可展示的中文错误。

## 3. 事件

| 事件 | 载荷 | 时机 | 前端处理 |
|---|---|---|---|
| `game-stopped` | `{ gameId, sessionSec, playtimeSec }` | 监控判定退出并完成结算后 | 移除会话、更新累计时长、Toast 本次分钟数 |
| `launch-failed` | `{ gameId, message }` | 启动抛错时（同时 reject 命令） | Toast 中文错误 |
| `settings-changed` | `Settings` | 首次关闭选择成功写入后 | 同步设置与排序，不重新载入游戏库 |
| `close-requested` | `CloseRequest \| null` | 待确认请求变化 | 显示对应自定义弹窗；空值关闭弹窗 |
| `superres-progress` | `{ gameId, taskId, preset, stage: "processing" \| "resizing" \| "saving", elapsedMs }` | 任务开始、每 500 ms 与进入保存阶段 | 更新阶段与已用时间；不显示剩余时间 |
| `superres-done` | `{ gameId, taskId, preset, file, elapsedMs }` | 派生图发布成功后 | 切换到增强图并 Toast 耗时 |
| `superres-failed` | `{ gameId, taskId, preset, message }` | 进程异常、产物无效、模型或辅助程序缺失 | Toast 中文错误，保持原图 |
| `superres-cancelled` | `{ gameId, taskId, preset, message }` | 取消完成并清理临时文件后 | 结束进度，Toast 已取消 |

事件由 Rust `Emitter` 广播；通用事件在 `App` 挂载时订阅，超分事件在详情页订阅，卸载时取消。事件不保证顺序，处理必须幂等（按 `gameId` 过滤，超分还需按 `taskId` 隔离任务）。

## 5. 变更检查清单

新增或修改命令时：

- [ ] 在 `src-tauri/src/commands.rs` 或对应领域模块实现，并注册到 `lib.rs` 的 `generate_handler!`。
- [ ] Rust 模型加 `camelCase` 与默认值；`src/types.ts` 同步。
- [ ] `src/lib/ipc.ts` 加方法，组件不直接写命令名。
- [ ] 更新本文件的签名表与错误说明。
- [ ] 更新 [后端实现.md](后端实现.md) 的实现/限制（若有行为变化）。
- [ ] 若影响界面，更新 [前端实现.md](前端实现.md) / [界面与交互.md](界面与交互.md)。
- [ ] 在 [版本记录.md](版本记录.md) 记录行为变化。
- [ ] 至少补一个前端或 Rust 测试；命令层算法补单元测试。
