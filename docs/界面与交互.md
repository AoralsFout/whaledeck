# 界面与交互

> 本文是布局尺寸、视觉令牌、交互时序、响应式与可访问性的**唯一权威**。
> 组件内部状态见 [前端实现.md](前端实现.md)，主题字段见 [数据模型.md](数据模型.md)。

---

## 1. 设计原则

1. **封面优先**：主区大面积展示封面，信息在需要时展开。
2. **一屏完成**：启动、收藏、编辑、联网、补全固定在底部操作栏，不来回滚动。
3. **安静但有反馈**：动效短、幅度小；所有异步操作有忙碌态或 Toast。
4. **键盘等价**：鼠标能做的，键盘也能做；焦点始终可见。
5. **内容可读**：无论深浅主题、是否有背景图，文字对比度优先于玻璃效果。

## 2. 布局

### 2.1 应用外壳

窗口控制组左侧增加同风格的调整把手按钮，使用四向移动图标，用于当前游戏的封面取景，显示条件见 §4.3「封面显示取景」：悬浮时向上滚轮放大、向下缩小，范围沿用封面设置；滚动即时预览，停止 250ms 后合并保存。左键按下锁定鼠标位置，以相对移动量实时预览封面，移动超过 3px 视为拖拽；释放后解锁并保存，拖拽不触发单击。Escape、失焦、切换游戏或打开弹窗取消未释放的拖拽并解锁。单击或键盘激活打开「设置 → 封面」并选中当前游戏，提供滑杆操作替代。无封面或图片未加载时仍可进入设置，但不调整取景；其他弹窗打开期间禁用入口。保存失败恢复已保存效果并提示；原图与增强图共用结果。

调整把手拖拽时，水平和垂直方向分别丢弃超出封面边界的位移；触边后反向移动鼠标，封面立即沿该方向移动，无需抵消此前越界的距离。

下图表示侧栏展开时的分区；侧栏覆盖在全窗口主区之上，默认隐藏。

```text
┌──────────────┬─────────────────────────────────────────────┐
│ Sidebar      │ 主区（游戏详情 / 空态）                      │
│ 258px        │ 封面背景 + 标题 + 可展开详情                  │
│ 搜索/筛选/   │                                             │
│ 排序/列表    │                                             │
│              ├─────────────────────────────────────────────┤
│              │ 操作栏（启动 / 收藏 / 编辑 / 联网 / 补全）    │
│              │ 统计栏（最近游玩 / 时长 / 分类 / 存档 / 来源）│
└──────────────┴─────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 侧栏 | 宽 258px；默认收在窗口左侧，展开时覆盖主区；关闭自动隐藏后常驻并为主区留出宽度；底部固定计数与设置入口 |
| 窗口控制 | 固定右上 `top: 12px; right: 12px`；40×36 左右按钮；关闭按钮 hover 红底 |
| 拖动区 | 顶部 52px，自动隐藏时 `left: 16px`、常驻时 `left: 258px`，`right: 156px`；不占布局 |
| 主区 | 自适应剩余宽度；最小高度 0，仅游戏详情区域滚动 |
| 操作栏 | 底栏第一行，`py: 16px`；主按钮最小宽 156px；图标按钮 40×40 |
| 统计栏 | 底栏第二行，`py: 12px`；项目间 `gap-x: 32px`；等宽数字 |
| 页面边距 | `clamp(24px, 3.2vw, 40px)`，左右统一 |

窗口默认 1280×820，最小 1000×640；无边框、透明、圆角 12px（最大化时 0），关闭系统原生窗口阴影。

普通窗口沿内缘绘制 1px 细描边，颜色使用 `--window-border`，与窗口圆角一致；描边覆盖内容和弹窗遮罩，不占布局空间、不拦截点击。最大化或全屏时隐藏描边。

- 自动隐藏模式下，桌面左边缘保留 12px 呼出区与居中细线提示；鼠标进入即展开侧栏，离开后等待 180ms 再收起，往返移动取消待收起动作。滑入/滑出使用 280ms 减速过渡，主区始终占满窗口，避免封面和内容反复缩放。关闭自动隐藏后侧栏始终展开，Escape 只将焦点返回主区。
- 搜索框或排序选择器仍有焦点、键盘正在侧栏内操作或从侧栏打开弹窗时保持展开。收起的侧栏不接收点击和 Tab 焦点；左边缘按钮支持 Tab、Enter/空格呼出，Escape 返回主区并收起。桌面单击游戏后保持展开以支持连续选择和双击启动。
- 窄屏继续通过「游戏库」按钮打开全屏导航，选择游戏或点击「返回详情」收起，不依赖悬停；跨越窄屏断点时收起导航。减少动态效果模式即时切换。

### 2.2 主区内容

- 背景：用户在「外观 → 背景图」设置图片后，所有项目的右侧展示区统一透出应用背景及其遮罩，不再叠加项目封面、增强图或无封面渐变；切换项目保持该背景，封面取景不影响它。图片加载期间或失败时显示主题底色，可更换或清除背景图。未设置或清除后，恢复项目封面 `object-cover` 全幅，无封面用主题渐变。两种背景的右侧展示区均覆盖同一层从底部向上减弱的黑色渐变，底部最深以承托操作与统计，上方保留图片细节；该渐变不接收指针事件，自定义背景仍叠加原有的可调遮罩强度。左侧栏继续遵循其独立背景设置，不增加这层渐变。
- 内容：顶部留 80px；标题区与底部操作、统计栏固定在各自位置，详情独占中间剩余空间滚动；详情底部留 48px，滚动区底部 40px 渐隐遮罩。
- 标题：3xl，叠加阴影；图标与应用名称位于同一行，分类/标签 chips 独立排列在该行下方；图标、名称与分类/标签位于滚动容器外，不随详情滚动。图标槽宽为名称单行行高，高度撑满名称行（名称换行时随整行增高），不包含下方分类/标签；图像完整显示、无内边距，使用 0.5px 细边框。
- 详情：移除展开/收起按钮；桌面鼠标悬浮标题或详情区域时显示，移出后隐藏；可通过 Tab 聚焦该区域并保持内部操作可见，无悬浮能力的设备直接显示详情。
- 详情节：简介、程序信息、存档备份、备注；宽度 ≥960px 时两列，第三项起占满。

### 2.2.1 展示页切换过渡

入口为「设置 → 外观 → 展示页过渡」，背景与文本使用独立、有可见标签的选择框，修改即时生效并自动保存；提供重播预览。背景提供无动画、模糊渐变、交叉透明度渐变，以及左到右、右到左、上到下、下到上滑动；方向指画面移动方向，新画面从相反边缘进入。文本提供无动画、透明度渐变、逐字位移、乱码过渡。默认值与存储见[数据模型.md](数据模型.md) §2.8。

背景过渡持续 480ms，新封面解码就绪后再开始，旧封面与取景保留到交接；无封面的主题渐变也参与切换。同一游戏的取景、原图/增强图更换不触发游戏切换动画。连续切换直接转向最新目标，只保留一份退场背景；退场背景不接受交互。首次展示不播放背景入场。

文本覆盖标题、分类/标签、简介、程序信息、备注和底部统计中的项目文本；透明度渐变为 220ms，逐字位移为 280ms 加总计最多 180ms 的错峰，乱码在 460ms 内从左到右恢复原文。长文本仅前 160 个字素参与逐字与乱码效果，其余直接显示；保留换行、空格、自然换行与原文的无障碍读取，不改变布局尺寸，不动画实时计时或操作按钮。切换后控件立即属于新游戏；旧计时、备份及确认状态照常清理。系统开启「减少动态效果」时直接显示最终背景与原文，取消乱码帧循环。

### 2.3 列表项

- 高约 56px；缩略图 32×32；标题 13px，副行 11px（相对时间 · 时长）。
- 项目缩略图优先使用项目图标；未设置、加载失败或文件损坏时显示应用图标，封面继续只用于封面区域。详情标题旁与表单图标预览沿用同一回退规则。
- 选中：主色 13% 背景 + 30% 描边。
- 运行中：右侧 6px 呼吸圆点；收藏：金色星标。
- 侧栏筛选 chips 最高 112px，可滚动；窗口窄时 96px。

### 3.1 品牌标识

- 应用采用 H2「鲸尾手柄 + 双层堆叠」标识：青色主体、深海蓝按键、透明背景，保持原比例，不增加表情或装饰底板。
- 程序、任务栏、托盘、侧栏、加载态、空态与默认项目图标使用同一源图生成的资源。侧栏品牌图标为 32×32px，旁边保留 WhaleDeck 与中文说明；关于页显示 64×64px 图标与 WhaleDeck 横版组合，文字使用当前主题的主文字色。
- 品牌源文件与批量生成方法见 [工程规范.md](工程规范.md) §1.1；运行时引用见 [前端实现.md](前端实现.md) §4.2。

## 4. 组件规范

### 4.1 按钮

| 变体 | 用途 | 视觉 |
|---|---|---|
| `.btn` | 默认 | 表面色 + 描边；hover 上浮 1px + 主色描边 + 柔光；active 缩放 0.98 |
| `.btn-primary` | 主操作 | 主色渐变、深色文字；hover 提亮 + 光晕 |
| `.btn-ghost` | 次要/图标 | 透明；hover 表面色 |
| `.btn-danger` | 删除/还原确认 | 红色 12% 背景 + 35% 描边 |
| `.btn-icon-glass` | 详情操作图标 | 黑 35% 玻璃 + 白图标；hover 上浮 1px、放大 1.025，active 缩放 0.97 |

所有按钮最小高 36px（窄屏 40–44px），禁用时透明度 0.45 且无位移。

- 详情操作栏的封面增强档位下拉框高 40px，与相邻图标按钮共用玻璃底色、描边及悬停、按下、禁用反馈；展开菜单沿用 §4.2.2，始终使用详情区的深色配色。
- 按钮的颜色、描边、光晕与亮度在 140ms 内平滑变化；按下形变 90ms，松手或移出后用 260ms 减速复位，可连续反向过渡，不等待动画结束才触发操作。
- 筛选、设置标签、主题卡片、关闭行为选项和小图标按钮使用同一套时序；按下幅度按控件尺寸收敛，列表项只改变底色与描边，不缩放文字或挤动布局。
- 上浮、放大与悬停提亮只用于支持精确鼠标悬停的设备，触屏保留按下反馈；禁用按钮无悬停反馈。系统开启「减少动态效果」时取消按钮形变与过渡。

### 4.2 输入与表单

- 输入高 38px，圆角 10px；聚焦主色描边 + 3px 柔光。
- 标签 12px 次要色；提示 12px；错误 12px 红色，`aria-invalid` + `aria-describedby`。
- 表单网格：两列；窄屏一列。字段间距 20–24px。
- 弹窗内容边距桌面 28px、窄屏 20px；标题 17px，正文/输入 14px，辅助 12px。
- 项目表单在封面下方提供独立图标行：80×80px 方形预览、等比例完整显示，旁边为「选择图标」与「移除图标」按钮，说明用于侧栏列表；窄屏允许换行。未选择或移除后按 §2.3 的规则显示默认图标。
- 详情操作栏的「自动补全」打开复用的项目表单，自动预填名称、开发商、备注、封面与图标中可获取的内容；原有非空值也可被预填，未获取到的内容保留原值。用户可逐项修改或「恢复原值」（本次打开表单前的值，含空值与空图像）；只有点击「确认保存」才更新记录，取消、关闭或 Escape 均放弃草稿。
- 项目表单中上述五项各提供「自动获取」按钮，只覆盖对应草稿字段，依据当前目标路径获取，不影响其他字段；新增项目填写路径后也可使用。获取不到时保留现值并提示，可继续手动编辑。名称、开发商、备注的按钮放在标签旁，图像按钮放在预览旁；按钮组可换行，恢复按钮在值未改变时禁用。
- 自动获取时显示「获取中…」及可感知的状态提示，暂时禁止编辑、重复获取与保存；允许取消并丢弃迟到结果。图片导入或保存期间继续禁止关闭，失败保留草稿以便重试。

### 4.2.1 数值滑块

- 背景遮罩、侧栏模糊度与透明度、侧栏背景及封面取景共用一种滑块：6px 圆角轨道，已调整部分使用主题可读主色 `--primary-ink`，剩余部分使用文字色与表面色混合的中性轨道；18px 圆形手柄使用面板底色、2px 主色描边和轻微阴影。
- 控件宽度随容器伸缩，桌面交互区域高 32px，窄屏或粗指针设备高 44px。进度始终与手柄中心对齐，拖动即时反馈，不对数值或进度做缓动。
- 精确指针悬停时手柄出现柔和光圈，按下时光圈加强；键盘聚焦显示 2px 可读主色外框及手柄光圈。反馈使用现有快速动效令牌，减少动态效果时取消过渡。
- 原生 range 保留方向键、Home/End、点击轨道及拖动；每项关联可见标签，显示当前数值与单位，并提供带单位的无障碍数值。禁用（含父 fieldset 禁用）时整体降低强调、不显示交互光圈；系统强制颜色模式使用系统颜色。

### 4.2.2 原生下拉框

- 侧栏排序、设置页选择器与封面增强档位保留原生单选 `select`，共用主题样式；收起时显示向下箭头，保留各处原有尺寸与底色。键盘聚焦显示 2px 可读主色外框，禁用（含父 fieldset 禁用）时降低透明度并取消悬停反馈。
- 支持 `appearance: base-select` 与 `::picker(select)` 的 WebView 使用原生可定制菜单：不透明 `--surface` 底色、主题文字及描边、12px 圆角、4px 内边距与轻微阴影，菜单与控件间隔 6px；侧栏继承局部配色，菜单不透出背景图片。
- 选项最小高 34px，左右留白 10px、圆角 7px；选中项使用淡主色底与末尾勾选标记，悬停及键盘定位使用更明显的主色底和内描边。窄屏或粗指针设备选项最小高 44px。菜单宽度跟随控件，最小 128px、最大为视口宽度减 24px；长选项允许换行，菜单最大高为 `min(320px, 70dvh)`，超出时内部滚动；保留浏览器的视口边缘避让。
- 不支持上述能力的环境继续使用系统菜单，并尽可能应用不透明选项底色与主题文字色；系统强制颜色模式保留系统菜单。Tab、方向键、确认、Escape 关闭与字符定位由浏览器处理，不维护另一份选择状态。

### 4.3 对话框

| 规格 | 值 |
|---|---|
| 最大宽度 | 默认 560；表单 680；联网 700；扫描 720；设置 780 |
| 外边距 | `64px 24px 24px`；窄屏 `64px 12px 12px` |
| 面板 | 主题表面 94% 底色 + 16px 圆角 + 阴影；仅遮罩做背景模糊，避免面板重复采样；设置固定高 `min(740px, 100%)` |
| 分区 | header / body / footer；body 独立滚动、`overscroll-behavior: contain` |
| 遮罩 | 黑 55%，与弹窗内容、阴影一起按 `--window-radius` 裁剪到窗口轮廓，四角保持透明；设置不做全窗口模糊，其他对话框保留 `blur(3px)` |
| 动效 | 淡入及轻微纵向位移 180ms，不缩放整块内容；设置标签页仅淡入 140ms |

- 设置页：标签栏固定，内容区滚动；桌面 28px 内容边距，窄屏 20px。「左侧栏」作为独立标签页排列在「外观」之后，外观页保留主题配色、明暗模式与应用背景。
- 设置滚动区独立限制布局和绘制范围；侧栏图片预览仅左侧栏页加载，滚动与打开常规页不等待图片。更改主题不重新生成游戏列表，选中与悬停样式由 CSS 更新。
- 左侧栏页按「侧栏效果」「背景与取景」分区。「自动隐藏」使用独立开关，支持点击和键盘空格键，以 `role="switch"` 和 `aria-checked` 表达状态。下方始终显示模糊度、底色透明度两个滑块，分别显示像素值和百分比，支持键盘调整；所有修改即时生效并保存，自动隐藏不影响背景设置。底色透明度范围 0–100%，步长 1%，默认 52%；不提供效果预设或透明度快捷选项。
- 左侧栏背景始终适配，显示方式见下方「侧栏背景适配」。底色遮罩由透明度控制，文字和控件保持不透明。图片与遮罩独立分层，保留 258px 宽度与独立列表滚动；窄屏导航也使用同一背景与透明度。无背景图片时继续透出应用背景。
- 有已显示的适配图时，侧栏自动从实际取景提取代表色，并结合主题底色、透明度及磨砂生成局部配色；上方控件优先参考其所在区域。搜索、筛选、排序、工具按钮、品牌文字、列表及底部入口共用协调的表面、文字、描边与选中态，主区、弹窗和品牌图标不跟随变色。灰度图片使用主题强调色兜底；无适配图恢复全局主题，取色失败使用主题色生成保守的局部配色。
- 搜索框、筛选、排序及工具按钮使用轻薄的中性底色，底部「设置」按钮共用顶部普通工具按钮的背景与描边。背景平均色只参与明暗选择与采样处的对比度校正，不直接给控件染色。深色/浅色的普通控件底色不透明度分别为 22%/38%，选中及添加按钮为 34%/52%，悬停为 28%/44%；图片取色只给选中态加入少量强调。描边半透明且轻淡，普通列表项不显示常驻描边，不恢复区域底色。普通文字（含次文字及占位提示）以采样背景上合成后的控件表面对比度至少 4.5∶1 为目标，焦点提示及收藏/运行标识以 3∶1 为目标；保留语义色相并按需校正明度，图片局部像素差异仍会影响实际对比度。图片交接时同步启用目标配色，不逐帧取色或动画文字颜色。
- 移除 `--sidebar-panel` 区域底色；顶部控件区的空隙、未选中且未悬停的列表项、空列表提示和底部容器直接透出侧栏背景。图片层和原有整幅遮罩仍按背景效果与透明度设置显示；直接叠在图片上的文字沿用动态明暗配色，不再承诺任意局部图片像素上的固定对比度。
- 使用游戏封面作为背景时，左右两侧及侧栏设置预览共用当前游戏的原图 / 效率档 / 质量档选择，沿用 §5 的缓存、偏好恢复与失败回退规则；查询尚未完成时保留已显示的背景，不先切回原图，不额外生成超分。侧栏仍使用独立的背景适配与取景；独立背景图片优先，不随封面选择变化。无独立背景时始终跟随当前游戏封面；无封面则透出应用背景，主题渐变由透明度控制。
- 模糊度范围 0–48 px、步长 1 px，默认值见[数据模型.md](数据模型.md) §2.2。模糊度为 0 时清晰显示图片，大于 0 时仅对图片层使用 `blur()` 与 `saturate(1.15)`；无图片时作用于后方背景。底色透明度为 100% 时移除侧栏底色、图片底色及主题渐变；配合模糊度 0 可实现原全透明背景效果。文字和控件不随滑块改变透明度或模糊度。图片统一向边缘扩展 72px 后裁切，调整滑块不重新生成适配图；窄屏导航仍通过按钮展开。

- 扫描/联网/表单/设置共用同一套 header/body/footer 规范。

#### 侧栏背景适配

入口为「设置 → 左侧栏 → 背景与取景」，始终显示，不随自动隐藏或滑块数值隐藏。适配默认且始终开启，不提供开关；「完整显示」「铺满裁切」「拉伸铺满」使用一行三等分的互斥选项，保留键盘操作。裁切支持水平 / 垂直取景和恢复居中。选择 / 更换图片按钮置于左侧预览容器内部、图片下方，清除按钮和背景来源随同排列。

图像调整保持左图右控件，窄屏缩小预览并允许控件文案换行，不横向滚动。预览采用真实侧栏比例，高度不超过 320px 或视口的 40%，只保留这一处图片预览；尺寸信息收进可展开的「图像信息」。预览清晰展示取景，磨砂及透明度以实际侧栏为准；切换参数生成期间先用原图展示新取景，避免把旧适配图当作新预览。点击「应用取景」成功后生效；「还原」、关闭或切换标签丢弃适配草稿。保存失败保留草稿和原实际效果，生成失败提供「重试生成」。无图展示空状态、禁用取景和应用，并提供选图入口；仅调整尺寸，不补图、不改变主区布局。

实际侧栏切换项目或背景来源时，保留上一张已显示的适配图及其取景与配色，待目标适配图解码和取色就绪后，复用「展示页过渡」中的背景方案交接；效果、方向、时长与减少动态效果规则见 §2.2.1。过渡只作用于图片层，两层各自保留取景与扩边，文字与控件立即使用目标配色，底色遮罩仍由透明度控制；连续切换只保留一份退场背景。不短暂展示居中的原图，首次加载不播放入场动画；目标无背景来源时立即清除图片及退场历史，之后重新出现图片仍视为首次加载。生成失败保留已显示的适配图和配色，可在设置中重试。

#### 封面显示取景

启用「外观 → 背景图」的全局背景时，隐藏本页的游戏选择、取景预览和调整控件，并隐藏窗口顶部的快捷取景手柄；封面页入口保留，进入后说明「已启用全局背景图，主区不再显示游戏封面，因此暂时隐藏封面取景设置」，提示到「设置 → 外观 → 背景图」清除图片后恢复。此时不显示确认保存的页脚提示；已保存的逐游戏取景保留，清除全局背景后恢复可用。是否启用以已保存的背景文件配置为准，加载中或加载失败也遵循此规则；切换到全局背景时卸载取景编辑器，丢弃未确认草稿。侧栏独立背景适配不受影响。

「设置 → 封面」可选择库内游戏，手动调整主区封面显示的截取范围。提供按当前主区比例的清晰预览、直接拖动画面、水平/垂直位置（0–100%）及缩放（100–300%），另有恢复居中、取消修改与确认保存。移动画面的方向与拖动一致；也可完全使用键盘操作滑杆。预览调整不会立即改变主区，关闭、切页或换游戏丢弃草稿；保存失败保留草稿与原效果。无封面时显示引导，加载失败可重试，禁止保存不可预览的图。

每款游戏独立保存取景，应用新的封面后重新从居中开始，不截断或覆盖原文件；增强图沿用同一取景。侧栏背景仍由原有适配功能控制。联网补全结果保留「应用封面和信息」，新增「应用并调整封面」；已有封面也可从弹窗的「调整当前封面」直接进入设置。原应用操作仍按原流程完成，取景必须单独确认。

### 4.4 Toast

- 右下角固定；最大宽 420px；玻璃底 + 状态色描边。
- 成功绿、错误红、信息主色；`role="status"`、`aria-live="polite"`。
- 普通通知 3.4 秒自动消失，可手动关闭；有弹窗时挂到 `dialog[open]` 内。
- 封面超分的档位、阶段和已用时间在右下角进度提示中持续显示，不再占用详情操作栏；取消按钮保留在操作栏。任务完成、失败或取消后立即隐藏进度提示，结果使用普通通知；离开当前详情时清理进度提示，返回后随任务状态恢复。进度与普通通知纵向排列，互不覆盖。

### 4.5 操作提示

- 首次悬停 1000ms 显示；已显示过后，600ms 内移到其他按钮立即显示；停止探索后恢复延迟。
- 键盘 `:focus-visible` 立即显示；Escape、点击操作、滚动、缩放窗口时收起。
- 提示最多 280px，自动避开视口边缘；不叠加原生 `title`。

## 6. 响应式与窗口

### 6.1 程序托盘与关闭行为

- 启动时创建程序托盘；左键单击或双击显示、还原并聚焦主窗口，右键菜单提供「显示主窗口」和「退出 WhaleDeck」。
- 关闭按钮、Alt+F4 与系统关闭请求统一按关闭行为处理。首次关闭且尚未选择时，用项目统一的自定义对话框说明「后台隐藏」继续计时、「直接关闭」退出程序；明确选择后记住偏好，取消或 Escape 保持窗口与偏好不变。文案提示可在「设置 → 常规 → 关闭行为」修改。
- 后台隐藏只隐藏窗口，保留托盘与进程监控；托盘的「退出 WhaleDeck」始终表示真正退出。
- 真正退出前，只要仍有受追踪会话，就弹出警告：「通过启动器运行的程序仍在运行。退出 WhaleDeck 后，这些程序会继续运行，但将无法继续追踪和记录运行时长。已运行时长会保存到退出时刻。」只有点「确认退出」才退出；取消、Escape 或关闭对话框均继续运行。窗口与托盘退出使用同一规则，重复请求只保留一个确认框。
- 关闭流程的对话框均复用 `Modal`；托盘退出需要确认时先显示、还原并聚焦主窗口。首次选择直接关闭后若取消运行中警告，关闭行为仍已保存。设置保存或退出结算失败时在自定义弹窗中显示错误并保持程序运行。
- 常规页用两个有说明的选项显示关闭行为；尚未选择时显示「首次关闭时询问」。保留现有主题与设置标签的键盘导航。

| 条件 | 行为 |
|---|---|
| 宽度 ≤ 700px | 侧栏变为全屏覆盖层，顶部显示「游戏库」按钮；主区占满；输入 16px 防缩放；侧栏工具与详情操作 ≥44px、弹窗按钮 40px；弹窗边距 12px / 内容 20px + 16px；表单单列 |
| 详情容器 ≥ 960px | 详情卡片两列 |
| 详情容器 ≤ 560px | 标题 26px；统计栏两列；主按钮占满一行 |
| 高度 ≤ 540px | 内容顶部 64px；操作/统计/底栏间距压缩；弹窗顶部 56px |
| 窗口最大化/全屏 | `data-window-expanded=true` → 圆角 0 |
| 系统减少动态效果 | 动画/过渡近似 0；hover/active 位移取消 |

## 7. 可访问性

- 所有交互元素可 Tab 到达；`:focus-visible` 统一 2px 主色描边、偏移 3px。
- 图标按钮必须有 `aria-label`；状态按钮用 `aria-pressed`；当前列表项用 `aria-current`。
- 对话框使用原生 `<dialog>` + `aria-label`；Tab 在面板内循环；关闭后焦点回到触发元素。
- 设置标签使用 `role="tablist"` / `role="tab"` / `role="tabpanel"`，支持左右方向键、Home、End。
- Toast 使用 `role="status"` + `aria-live="polite"`；错误字段用 `role="alert"`。
- 提示浮层 `role="tooltip"`，并通过 `aria-describedby` 关联触发按钮。
- 装饰性图标 `aria-hidden="true"`；图片 `alt=""`（纯装饰）或可读标题。
- 主要触控目标窄屏不小于 44px（弹窗按钮最低 40px）；不使用仅靠 hover 才能完成的操作。
- 文案使用简体中文，错误说明「发生了什么 + 可以怎么做」。

## 8. 验收清单

### 8.1 桌面（1280×820）

- [ ] 侧栏默认收起，左边缘呼出后宽 258px，列表可搜索/筛选/排序，选中态清晰；移出收起，主区尺寸不变。
- [ ] 搜索/排序/弹窗不被自动收起中断；隐藏后不可 Tab 进入，键盘呼出与 Escape 收起可用。
- [ ] 主区封面铺满，底部操作栏与统计栏固定且不遮挡滚动内容。
- [ ] 无封面时显示渐变，不出现 exe 图标。
- [ ] 详情遵循 §2.2 的显示规则，滚动时图标、名称与分类/标签位置不变。

### 8.2 最小窗口（1000×640）与矮窗口（≤540px）

- [ ] 底栏、表单、弹窗不溢出，可滚动完成操作。
- [ ] 统计栏不换行错位；按钮不重叠。

### 8.3 窄屏（375px 宽）

- [ ] 侧栏作为覆盖层打开/关闭，主区占满。
- [ ] 表单单列，输入字号 16px，按钮高度 ≥44px。
- [ ] 弹窗内容边距 20px，标题/正文不截断。

### 8.4 主题与可访问性

- [ ] 深色、浅色、跟随系统切换即时生效并持久化。
- [ ] 自定义主色/强调色、背景图、遮罩强度均生效。
- [ ] 侧栏适配图的冷暖、黑白、透明及强反差图片在深浅主题、不同透明度和磨砂/清晰模式下配色协调，文字、占位提示、焦点和按下态清晰；等待适配与失败期间保留旧图旧色，无图恢复主题，主区和设置弹窗配色不受影响。
- [ ] 仅键盘可完成：筛选、选择、启动、编辑、关闭弹窗。
- [ ] 系统开启「减少动态效果」后无位移动画。
