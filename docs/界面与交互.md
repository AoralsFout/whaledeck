# 界面与交互

> 本文是布局尺寸、视觉令牌、交互时序、响应式与可访问性的**唯一权威**。
> 组件内部状态见 [前端实现.md](前端实现.md)，主题字段见 [数据模型.md](数据模型.md)。

---

## 1. 设计原则

1. **封面优先**：主区大面积展示封面，信息在需要时展开。
2. **一屏完成**：启动、收藏、编辑、联网、补全固定在底部操作栏，不来回滚动。
3. **安静但有反馈**：动效短、幅度小；所有异步操作有忙碌态或 Toast。
4. **键盘等价**：鼠标能做的，键盘也能做；焦点始终可见。
5. **内容可读**：无论深浅主题、是否有背景图，文字对比度优先于玻璃效果。

## 2. 布局

### 2.1 应用外壳

下图表示侧栏展开时的分区；侧栏覆盖在全窗口主区之上，默认隐藏。

```text
┌──────────────┬─────────────────────────────────────────────┐
│ Sidebar      │ 主区（游戏详情 / 空态）                      │
│ 258px        │ 封面背景 + 标题 + 可展开详情                  │
│ 搜索/筛选/   │                                             │
│ 排序/列表    │                                             │
│              ├─────────────────────────────────────────────┤
│              │ 操作栏（启动 / 收藏 / 编辑 / 联网 / 补全）    │
│              │ 统计栏（最近游玩 / 时长 / 分类 / 存档 / 来源）│
└──────────────┴─────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 侧栏 | 宽 258px；默认收在窗口左侧，展开时覆盖主区；关闭自动隐藏后常驻并为主区留出宽度；底部固定计数与设置入口 |
| 窗口控制 | 固定右上 `top: 12px; right: 12px`；40×36 左右按钮；关闭按钮 hover 红底 |
| 拖动区 | 顶部 52px，自动隐藏时 `left: 16px`、常驻时 `left: 258px`，`right: 156px`；不占布局 |
| 主区 | 自适应剩余宽度；最小高度 0，可滚动 |
| 操作栏 | 底栏第一行，`py: 16px`；主按钮最小宽 156px；图标按钮 40×40 |
| 统计栏 | 底栏第二行，`py: 12px`；项目间 `gap-x: 32px`；等宽数字 |
| 页面边距 | `clamp(24px, 3.2vw, 40px)`，左右统一 |

窗口默认 1280×820，最小 1000×640；无边框、透明、圆角 12px（最大化时 0）。

- 自动隐藏模式下，桌面左边缘保留 12px 呼出区与居中细线提示；鼠标进入即展开侧栏，离开后等待 180ms 再收起，往返移动取消待收起动作。滑入/滑出使用 280ms 减速过渡，主区始终占满窗口，避免封面和内容反复缩放。关闭自动隐藏后侧栏始终展开，Escape 只将焦点返回主区。
- 搜索框或排序选择器仍有焦点、键盘正在侧栏内操作或从侧栏打开弹窗时保持展开。收起的侧栏不接收点击和 Tab 焦点；左边缘按钮支持 Tab、Enter/空格呼出，Escape 返回主区并收起。桌面单击游戏后保持展开以支持连续选择和双击启动。
- 窄屏继续通过「游戏库」按钮打开全屏导航，选择游戏或点击「返回详情」收起，不依赖悬停；跨越窄屏断点时收起导航。减少动态效果模式即时切换。

### 2.2 主区内容

- 背景：封面 `object-cover` 全幅，底部渐变压暗；无封面用主题渐变。
- 内容：底部对齐，`padding-top: 80px`，底部留 48px，滚动区底部 40px 渐隐遮罩。
- 标题：3xl，叠加阴影；下方分类/标签 chips。
- 详情：默认收起；桌面 hover 展开，键盘 `focus-within` 展开，点击「游戏详情」固定展开（`data-expanded`）。
- 详情节：简介、程序信息、存档备份、备注；宽度 ≥960px 时两列，第三项起占满。

### 2.3 列表项

- 高约 56px；缩略图 32×32；标题 13px，副行 11px（相对时间 · 时长）。
- 项目缩略图优先使用项目图标；未设置、加载失败或文件损坏时显示应用图标，封面继续只用于封面区域。详情标题旁与表单图标预览沿用同一回退规则。
- 选中：主色 13% 背景 + 30% 描边。
- 运行中：右侧 6px 呼吸圆点；收藏：金色星标。
- 侧栏筛选 chips 最高 112px，可滚动；窗口窄时 96px。

### 3.1 品牌标识

- 应用采用 H2「鲸尾手柄 + 双层堆叠」标识：青色主体、深海蓝按键、透明背景，保持原比例，不增加表情或装饰底板。
- 程序、任务栏、托盘、侧栏、加载态、空态与默认项目图标使用同一源图生成的资源。侧栏品牌图标为 32×32px，旁边保留 WhaleDeck 与中文说明；关于页显示 64×64px 图标与 WhaleDeck 横版组合，文字使用当前主题的主文字色。
- 品牌源文件与批量生成方法见 [工程规范.md](工程规范.md) §1.1；运行时引用见 [前端实现.md](前端实现.md) §4.2。

## 4. 组件规范

### 4.1 按钮

| 变体 | 用途 | 视觉 |
|---|---|---|
| `.btn` | 默认 | 表面色 + 描边；hover 上浮 1px + 主色描边 + 柔光；active 缩放 0.98 |
| `.btn-primary` | 主操作 | 主色渐变、深色文字；hover 提亮 + 光晕 |
| `.btn-ghost` | 次要/图标 | 透明；hover 表面色 |
| `.btn-danger` | 删除/还原确认 | 红色 12% 背景 + 35% 描边 |
| `.btn-icon-glass` | 详情操作图标 | 黑 35% 玻璃 + 白图标；hover 上浮 1px、放大 1.025，active 缩放 0.97 |

所有按钮最小高 36px（窄屏 40–44px），禁用时透明度 0.45 且无位移。

- 按钮的颜色、描边、光晕与亮度在 140ms 内平滑变化；按下形变 90ms，松手或移出后用 260ms 减速复位，可连续反向过渡，不等待动画结束才触发操作。
- 筛选、设置标签、主题卡片、关闭行为选项和小图标按钮使用同一套时序；按下幅度按控件尺寸收敛，列表项只改变底色与描边，不缩放文字或挤动布局。
- 上浮、放大与悬停提亮只用于支持精确鼠标悬停的设备，触屏保留按下反馈；禁用按钮无悬停反馈。系统开启「减少动态效果」时取消按钮形变与过渡。

### 4.2 输入与表单

- 输入高 38px，圆角 10px；聚焦主色描边 + 3px 柔光。
- 标签 12px 次要色；提示 12px；错误 12px 红色，`aria-invalid` + `aria-describedby`。
- 表单网格：两列；窄屏一列。字段间距 20–24px。
- 弹窗内容边距桌面 28px、窄屏 20px；标题 17px，正文/输入 14px，辅助 12px。
- 项目表单在封面下方提供独立图标行：80×80px 方形预览、等比例完整显示，旁边为「选择图标」与「移除图标」按钮，说明用于侧栏列表；窄屏允许换行。未选择或移除后按 §2.3 的规则显示默认图标。
- 详情操作栏的「自动补全」打开复用的项目表单，自动预填名称、开发商、备注、封面与图标中可获取的内容；原有非空值也可被预填，未获取到的内容保留原值。用户可逐项修改或「恢复原值」（本次打开表单前的值，含空值与空图像）；只有点击「确认保存」才更新记录，取消、关闭或 Escape 均放弃草稿。
- 项目表单中上述五项各提供「自动获取」按钮，只覆盖对应草稿字段，依据当前目标路径获取，不影响其他字段；新增项目填写路径后也可使用。获取不到时保留现值并提示，可继续手动编辑。名称、开发商、备注的按钮放在标签旁，图像按钮放在预览旁；按钮组可换行，恢复按钮在值未改变时禁用。
- 自动获取时显示「获取中…」及可感知的状态提示，暂时禁止编辑、重复获取与保存；允许取消并丢弃迟到结果。图片导入或保存期间继续禁止关闭，失败保留草稿以便重试。

### 4.3 对话框

| 规格 | 值 |
|---|---|
| 最大宽度 | 默认 560；表单 680；联网 700；扫描 720；设置 780 |
| 外边距 | `64px 24px 24px`；窄屏 `64px 12px 12px` |
| 面板 | 主题表面 94% 底色 + 16px 圆角 + 阴影；仅遮罩做背景模糊，避免面板重复采样；设置固定高 `min(740px, 100%)` |
| 分区 | header / body / footer；body 独立滚动、`overscroll-behavior: contain` |
| 遮罩 | 黑 55%；设置不做全窗口模糊，其他对话框保留 `blur(3px)` |
| 动效 | 淡入及轻微纵向位移 180ms，不缩放整块内容；设置标签页仅淡入 140ms |

- 设置页：标签栏固定，内容区滚动；桌面 28px 内容边距，窄屏 20px。
- 设置滚动区独立限制布局和绘制范围；侧栏图片预览仅外观页加载，滚动与打开常规页不等待图片。更改主题不重新生成游戏列表，选中与悬停样式由 CSS 更新。
- 外观页「左侧栏」分组提供独立的「自动隐藏」「半透明磨砂」开关，可组合使用，切换不清除原背景与透明度。保留选择/更换独立背景、清除背景、透明度滑杆（0–100%，步长 1%）及「不透明 / 半透明 / 全透明」快捷选项。显示当前百分比，修改即时生效并保存。默认 52%，快捷半透明为 50%。
- 未启用适配时，左侧栏图片在侧栏范围居中 cover 裁切；启用后的显示方式见下方「侧栏背景适配」。底色遮罩由透明度控制，文字和控件保持不透明。图片与遮罩独立分层，保留 258px 宽度与独立列表滚动；窄屏导航也使用同一背景与透明度。无独立图片时继续透出应用背景；全透明表示移除底色遮罩。
- 开启半透明磨砂后，独立图片优先；未设置独立图片时跟随当前游戏原始封面，无封面则透出应用背景及主题渐变。仅图片层使用 `blur(24px) saturate(1.15)`，向边缘扩展 36px 后裁切，配合透明底色与细描边；深浅主题下文字均保持清晰。窄屏保留效果开关，但导航统一通过按钮展开，不强制常驻。
- 同组提供独立「全透明背景」开关，默认关闭，即时生效并自动保存。开启时清晰显示背景图片，移除图片模糊、后方背景磨砂、侧栏底色、图片底色及主题渐变；无图片时直接透出窗口内后方画面。文字与控件不改变透明度，侧栏布局、尺寸和图片取景规则不变。与半透明磨砂同时开启时清晰效果优先，关闭后恢复原设置；透明度控件在此期间禁用并显示说明，不改已保存的数值。背景图片和适配继续可用，完整显示的留空区域透出后方画面；支持自动隐藏与窄屏导航组合。
- 扫描/联网/表单/设置共用同一套 header/body/footer 规范。

#### 侧栏背景适配

入口为「设置 → 外观 → 左侧栏 → 背景适配」。原有自动隐藏、磨砂、背景选择及透明度保留。适配开关和参数单独编辑，初始关闭；提供完整显示、铺满裁切、拉伸铺满，裁切支持水平 / 垂直取景和恢复居中。关闭适配恢复已有居中 cover 显示。

预览采用真实侧栏比例，高度不超过 240px 或视口的 30%，并显示源图、侧栏 CSS 尺寸与生成像素；预览优先清晰展示取景，磨砂及透明度以实际侧栏为准。点击「应用适配」成功后生效；「取消修改」、关闭或切换标签丢弃适配草稿。保存失败保留草稿和原实际效果，生成失败提供「重试生成」。无图提示选择侧栏背景或开启磨砂使用当前游戏封面；仅调整尺寸，不补图、不改变主区布局。

#### 封面显示取景

「设置 → 封面」可选择库内游戏，手动调整主区封面显示的截取范围。提供按当前主区比例的清晰预览、直接拖动画面、水平/垂直位置（0–100%）及缩放（100–300%），另有恢复居中、取消修改与确认保存。移动画面的方向与拖动一致；也可完全使用键盘操作滑杆。预览调整不会立即改变主区，关闭、切页或换游戏丢弃草稿；保存失败保留草稿与原效果。无封面时显示引导，加载失败可重试，禁止保存不可预览的图。

每款游戏独立保存取景，应用新的封面后重新从居中开始，不截断或覆盖原文件；增强图沿用同一取景。侧栏背景仍由原有适配功能控制。联网补全结果保留「应用封面和信息」，新增「应用并调整封面」；已有封面也可从弹窗的「调整当前封面」直接进入设置。原应用操作仍按原流程完成，取景必须单独确认。

### 4.4 Toast

- 右下角固定；最大宽 420px；玻璃底 + 状态色描边。
- 成功绿、错误红、信息主色；`role="status"`、`aria-live="polite"`。
- 普通通知 3.4 秒自动消失，可手动关闭；有弹窗时挂到 `dialog[open]` 内。
- 封面超分的档位、阶段和已用时间在右下角进度提示中持续显示，不再占用详情操作栏；取消按钮保留在操作栏。任务完成、失败或取消后立即隐藏进度提示，结果使用普通通知；离开当前详情时清理进度提示，返回后随任务状态恢复。进度与普通通知纵向排列，互不覆盖。

### 4.5 操作提示

- 首次悬停 1000ms 显示；已显示过后，600ms 内移到其他按钮立即显示；停止探索后恢复延迟。
- 键盘 `:focus-visible` 立即显示；Escape、点击操作、滚动、缩放窗口时收起。
- 提示最多 280px，自动避开视口边缘；不叠加原生 `title`。

## 5. 交互规则

| 场景 | 规则 |
|---|---|
| 选择游戏 | 单击列表项切换详情（窄屏同时关闭导航） |
| 启动 | 双击列表项，或点底栏主按钮 |
| 运行中 | 主按钮禁用并显示 `运行中 HH:MM:SS`；列表显示呼吸圆点 |
| 详情展开 | 桌面 hover；键盘焦点；点击按钮固定；触屏只能点击按钮 |
| 收藏 | 图标按钮切换；不关闭详情 |
| 删除 | 二次确认；提示「本地文件不会动」 |
| 时长修正 | 展开详情 → 输入分钟 → 保存；非法输入提示 |
| 备份还原 | 点「还原」进入确认态，再点「确认还原」；取消不执行 |
| 导入 | 点「导入游戏库」→「确认覆盖导入」；必须先导出备份 |

## 6. 响应式与窗口

### 6.1 程序托盘与关闭行为

- 启动时创建程序托盘；左键单击或双击显示、还原并聚焦主窗口，右键菜单提供「显示主窗口」和「退出 WhaleDeck」。
- 关闭按钮、Alt+F4 与系统关闭请求统一按关闭行为处理。首次关闭且尚未选择时，用项目统一的自定义对话框说明「后台隐藏」继续计时、「直接关闭」退出程序；明确选择后记住偏好，取消或 Escape 保持窗口与偏好不变。文案提示可在「设置 → 常规 → 关闭行为」修改。
- 后台隐藏只隐藏窗口，保留托盘与进程监控；托盘的「退出 WhaleDeck」始终表示真正退出。
- 真正退出前，只要仍有受追踪会话，就弹出警告：「通过启动器运行的程序仍在运行。退出 WhaleDeck 后，这些程序会继续运行，但将无法继续追踪和记录运行时长。已运行时长会保存到退出时刻。」只有点「确认退出」才退出；取消、Escape 或关闭对话框均继续运行。窗口与托盘退出使用同一规则，重复请求只保留一个确认框。
- 关闭流程的对话框均复用 `Modal`；托盘退出需要确认时先显示、还原并聚焦主窗口。首次选择直接关闭后若取消运行中警告，关闭行为仍已保存。设置保存或退出结算失败时在自定义弹窗中显示错误并保持程序运行。
- 常规页用两个有说明的选项显示关闭行为；尚未选择时显示「首次关闭时询问」。保留现有主题与设置标签的键盘导航。

| 条件 | 行为 |
|---|---|
| 宽度 ≤ 700px | 侧栏变为全屏覆盖层，顶部显示「游戏库」按钮；主区占满；输入 16px 防缩放；侧栏工具与详情操作 ≥44px、弹窗按钮 40px；弹窗边距 12px / 内容 20px + 16px；表单单列 |
| 详情容器 ≥ 960px | 详情卡片两列 |
| 详情容器 ≤ 560px | 标题 26px；统计栏两列；主按钮占满一行 |
| 高度 ≤ 540px | 内容顶部 64px；操作/统计/底栏间距压缩；弹窗顶部 56px |
| 窗口最大化/全屏 | `data-window-expanded=true` → 圆角 0 |
| 系统减少动态效果 | 动画/过渡近似 0；hover/active 位移取消 |

## 7. 可访问性

- 所有交互元素可 Tab 到达；`:focus-visible` 统一 2px 主色描边、偏移 3px。
- 图标按钮必须有 `aria-label`；状态按钮用 `aria-pressed`；当前列表项用 `aria-current`。
- 对话框使用原生 `<dialog>` + `aria-label`；Tab 在面板内循环；关闭后焦点回到触发元素。
- 设置标签使用 `role="tablist"` / `role="tab"` / `role="tabpanel"`，支持左右方向键、Home、End。
- Toast 使用 `role="status"` + `aria-live="polite"`；错误字段用 `role="alert"`。
- 提示浮层 `role="tooltip"`，并通过 `aria-describedby` 关联触发按钮。
- 装饰性图标 `aria-hidden="true"`；图片 `alt=""`（纯装饰）或可读标题。
- 主要触控目标窄屏不小于 44px（弹窗按钮最低 40px）；不使用仅靠 hover 才能完成的操作。
- 文案使用简体中文，错误说明「发生了什么 + 可以怎么做」。

### 8.1 桌面（1280×820）
