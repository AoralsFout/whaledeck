## 2. 状态分层

### 2.1 全局状态：`useLibrary`

一个 Zustand store，持有游戏库、设置、运行会话、导航/搜索/排序、选中项、对话框开关、Toast 与所有动作。

**状态字段**

| 字段 | 说明 |
|---|---|
| `games` | 完整游戏库（含隐藏项） |
| `settings` | 设置；`null` 表示尚未加载 |
| `sessions` | 运行中的会话 |
| `ready` | 初次加载完成（成功或失败） |
| `busy` | 表单保存中 |
| `query` / `nav` / `sort` / `selectedId` | 视图状态 |
| `formOpen` / `editing` | 新增/编辑对话框 |
| `settingsOpen` / `scanOpen` / `metaOpen` | 其他对话框 |
| `toast` | 单条通知，3.4 秒后自动消失 |

**初始化**

`init()` 并行执行 `listGames`、`getSettings`、`getSessions`，成功后写入 `games/settings/sessions`，并用 `settings.sort` 初始化排序。失败时仍把 `ready` 置真并 Toast，保证窗口不会永久隐藏。

**写入规则**

- 统一经过 `persistGame`：调用 `save_game`，**只接受后端返回的记录**，按 `id` 替换或追加。
- `saveGame`：`busy` 包裹；成功后关闭表单、清空 `editing`、选中保存项；若保存项不在当前筛选结果内，重置为「全部」或「已隐藏」并清空搜索。
- `toggleFavorite`：复用 `persistGame`，不关闭表单、不切换选择。
- `deleteGame`：成功后从列表移除；若删除的是当前项，`selectedId = null`，由视图规则回落到首项。
- `applyGame`：只替换已存在的记录（用于元数据/自动补全返回），未知 `id` 忽略。
- 设置：`updateSettings` 先更新内存再保存，失败 Toast；`setSort` 也写设置，但失败静默（不打断排序）。

**启动与结算**

- `launchGame`：调用 `launch_game` 成功后才更新 `lastPlayedAt`；`pid` 非空时向 `sessions` 插入（先移除同游戏旧会话）；`pid` 为空时只提示「已用系统默认程序打开」。
- `handleStopped`：移除会话、用 `playtimeSec` 覆盖累计时长、Toast「本次游玩 N 分钟」（至少 1 分钟）。
- `handleLaunchFailed`：直接 Toast 错误。

**批量加入**

- `addScannedGames` 通过 `additionsQueue` **串行化**多个批次，避免并发重复写入。
- 每项按 `gamePathKey`（`trim`、`/`→`\`、小写）与当前 `games` 比较去重，因此同批次内已加入的项也会被后续项视为重复。
- 顺序写入；每成功一项立即更新库；遇到首个错误停止，`remaining` 为从失败项起的未加入项，`skipped` 记录跳过的重复项。
- 失败 Toast 包含「已加入 N 个 / 剩余 M 个 / 具体原因」；部分失败时扫描窗口保持打开，成功项变为「已在库中」。
- 空批次直接返回空结果，不发请求、不改通知。

**Toast**

- 全局单条；新 Toast 会清掉旧定时器；默认 3.4 秒；可手动关闭。

### 2.2 派生状态：`useLibraryView`

`useMemo(getLibraryView(games, nav, query, sort, selectedId))`：

1. `filterGames`：隐藏项只在 `hidden` 视图出现；`favorites` 只留收藏；`category` 精确匹配；搜索对 `title + category + tags` 做小写包含匹配。
2. `sortGames`：
   - `recent`（默认）：收藏优先，再按 `lastPlayedAt` 降序（`null` 视为 0）；
   - `title`：`localeCompare(..., "zh-Hans-CN")`；
   - `playtime`：累计秒数降序；
   - `added`：加入时间降序。
3. 选择：当前 `selectedId` 仍在可见列表则保留，否则取首项，列表为空则 `null`。

`App` 在 `ready` 后把 `selectedId` 同步为派生结果，保证删除、筛选、搜索后详情不指向列表外。

### 2.3 对话框级 store

- **`createMetaSearch(initialKeyword, deps)`**：每次打开弹窗创建；内部 `version` 递增。
  - 有效提交（非空关键词）时 `request = ++version`；只有 `request === version` 才能写结果、结束加载、发空结果/错误通知。
  - 切换来源：清空结果、结束加载、使旧请求失效，不自动搜索；重复点当前来源不打断。
  - 编辑输入不触发搜索；关闭弹窗调用 `invalidate()`，迟到响应不再改状态。
- **`createSaveBackups(gameId, deps)`**：详情页按游戏创建；`lifetime` 标识生命周期。
  - `connect()` 重置状态并开始初始读取，返回清理函数；清理后所有迟到响应被丢弃。
  - `refresh` 用 `listRequest` 只接受最新一次列表读取，避免初始读取晚返回覆盖备份后的新列表。
  - 备份与还原共享 `busy`；还原只接受当前列表中已选中的文件；备份成功先接纳返回记录，再刷新列表；刷新失败保留已知记录与成功提示。
- **组件本地状态**：表单草稿、详情展开、删除确认、时长修正、应用中等，均不进入全局 store。

## 3. 组件职责

| 组件 | 职责 | 关键行为 |
|---|---|---|
| `App` | 外壳与生命周期 | 初始化、事件订阅、默认选中、主题/背景、窗口显示、窄屏导航开关 |
| `Sidebar` | 导航、搜索、排序、列表 | 分类 chips、42px 左右列表项、缩略图（图标→封面→首字母）、双击启动、运行中圆点、收藏星标、底部计数 |
| `GameDetail` | 沉浸式详情 | 封面背景、标题/标签、悬停或点击展开详情、底部固定启动栏与统计栏、时长修正、复制路径、删除确认、自动补全、存档备份 |
| `GameForm` | 新增/编辑 | 草稿、名称/路径校验、文件/文件夹选择、封面导入、工作目录、分类建议、标签/额外进程名、存档目录、收藏/隐藏 |
| `SettingsPanel` | 设置 | 四个标签页、主题即时生效、背景图、分类管理、导出/导入、数据目录、关于 |
| `ScanDialog` | 扫描与批量加入 | 选目录、候选列表、已存在置灰、全选/反选、部分失败保留剩余选择 |
| `MetaDialog` | 联网补全 | 来源切换、搜索、结果列表、应用、无结果时手动选封面 |
| `Modal` | 对话框基础 | 原生 `<dialog>`、焦点约束、Escape、遮罩按下/抬起判定、焦点返回 |
| `ActionTooltips` | 操作栏提示 | 首次 1000ms、探索期 600ms、键盘聚焦立即显示、Escape/滚动/点击收起 |
| `Toast` | 全局通知 | 3.4 秒、`role="status"`、有弹窗时挂到 `dialog[open]` |
| `EmptyState` | 空态 | 空库引导 / 筛选无结果 + 清除筛选 |
| `WindowChrome` | 无边框窗口 | 拖动区、最小化/最大化/关闭、监听最大化状态、非 Tauri 环境禁用 |

### 3.1 `GameDetail` 细节

- 由 `App` 以 `key={selected.id}` 挂载：切换游戏即重建本地状态，避免旧备份/旧计时串入。
- 背景只用 `coverFile`，无封面时用主题渐变；**不使用图标当背景**。
- 计时：有运行会话时每秒按 `Date.now() - startedAt` 刷新；无会话归零。
- `processLike = isProcessTarget(exePath)` 决定按钮文案（开始游戏 / 用默认程序打开）、统计栏是否显示时长、是否显示工作目录。
- 操作栏：启动、收藏、编辑、联网补全、自动补全；提示文案通过 `data-tooltip` 提供。
- 自动补全：调用 `autofill`，按 `icon`、`cover`、`filled` 拼提示；没有封面时提示改用联网补全或手动选择。
- 存档备份：`game.savePaths.length === 0` 显示引导；否则显示备份按钮与最近 5 条；还原需两次点击。
- 详情展开：桌面 hover 展开、键盘聚焦展开、点击按钮固定展开；`data-expanded` 控制。

### 3.2 `GameForm` 细节

- 新记录在打开时生成 `id`，因此选封面时可立即按 `id` 命名；取消保存可能留下孤立封面文件（见 §7）。
- 目标选择：文件 → 自动补标题（文件名去扩展名）与工作目录；文件夹 → 标题取目录名，工作目录不自动填。
- 校验：名称、目标路径必填；错误显示在字段下并把焦点移到第一个错误。
- 标签与额外进程名：按中英文逗号拆分、去空白。
- 存档目录：逐个选择、可编辑、可移除；保存时 trim 并丢弃空项。
- 封面：选择后立即复制到数据目录并预览；保存时只提交文件名。

### 3.3 弹窗与浮层

- `Modal` 使用原生 `dialog.showModal()`，获得焦点陷阱与背景 inert；内部再显式处理 Tab 循环。
- 关闭条件：Escape；同一次主指针在遮罩按下并在面板外抬起；取消/关闭按钮。内部拖选到外部、外部拖到内部均不关闭。
- 卸载时恢复打开前的焦点。
- `Toast` 在弹窗打开时 portal 到 `dialog[open]`，否则到 `#root`，避免被 dialog 顶层遮住。
- `ActionTooltips` 用 portal 渲染到 `#root`，定位避开视口边缘；`aria-describedby` 动态挂到触发按钮。

## 4. 启动、主题与资源

### 4.1 启动

1. `main.tsx`：Tauri 环境设置 `document.documentElement.dataset.starting = "true"`。
2. `App` 挂载后 `init()`。
3. `ready` 后 `showWindowWhenReady()`：`waitForAssets()` → `document.fonts.ready` → 两帧（隐藏 WebView 中每帧 100ms 兜底）→ `show()` → 删除 starting → `setFocus()`。
4. 组件卸载时取消后续显示。

### 4.2 资源

- `loadAssetUrl(kind, file)`：`asset_path` → `convertFileSrc` → `new Image().decode()`。
- 整个流程 3 秒超时；失败/超时返回 `null`，不阻塞窗口。
- `pendingAssets` 记录未完成请求；`waitForAssets()` 循环等待全部结束。
- `useAssetUrl` 用 `{kind, file, url}` 三元组防止切换游戏时旧图覆盖新图。

### 4.3 主题

- `applyTheme(theme)` 写入 `data-mode`、`data-preset`、`--primary`、`--accent`、`--primary-rgb`、`--accent-rgb`、`--bg-dim`。
- `presetToTheme` 只替换 `preset/primary/accent`，保留模式、背景、遮罩。
- `system` 模式监听 `prefers-color-scheme` 变化重新应用。
- 背景图 URL 在 `App` 的 layout effect 写入 `--bg-image`，避免首帧闪烁。

### 4.4 窗口

- `WindowChrome` 只在 Tauri 环境拿到窗口对象；浏览器预览中按钮禁用。
- 拖动区不占布局空间；双击最大化由 Tauri 处理。
- 监听 resize，把最大化/全屏状态写入 `data-window-expanded`，CSS 据此把圆角置 0。

## 5. 格式化规则

| 函数 | 规则 |
|---|---|
| `formatPlaytime` | ≤0「未玩过」；<1 分钟「不到 1 分钟」；<60 分钟「N 分钟」；<24 小时「N 小时 M 分钟」；否则「N 天 M 小时」 |
| `formatTimer` | `HH:MM:SS`，负数归零 |
| `formatRelative` | 未来/60 秒内「刚刚」；分钟、小时；1 天「昨天」；<30 天「N 天前」；否则 `formatDate` |
| `formatDate` | `YYYY-MM-DD`（本地时区） |
| `titleFromPath` | 取最后一段，去掉 `.exe`（大小写不敏感）；文件夹由表单单独取目录名 |
| `dirFromPath` | 取最后一个 `\` 或 `/` 前的部分 |
| `shortPath` | 超过长度保留尾部并加 `…` |
| `formatBytes` | B / KB / MB，一位小数 |

## 7. 已知边界（前端）

1. `MetaDialog` 的「手动选择封面」只调用 `importCover` 更新文件与当前内存记录，没有调用 `save_game`；刷新/重启后记录可能仍指向旧封面。需要持久化时应补保存。
2. `GameForm` 选封面会立即写文件；取消表单不会清理，可能留下以该 `id` 命名的孤儿文件。
3. 资源加载 3 秒超时后返回 `null`，不会自动重试；需要重新挂载（切换游戏/重开应用）才会再次请求。
4. `formatRelative` 在渲染时取当前时间；列表不会随时间自动刷新，直到下一次状态变化。
5. 整库导入后调用 `init()`，但不重置 `nav/query/selectedId`；由视图规则回落到首项。
6. 搜索不覆盖备注、开发商、简介，只匹配标题、分类、标签。

## 8. 扩展指南

### 8.1 新增一个命令

1. 先在 [接口契约.md](接口契约.md) 写签名与错误。
2. Rust 实现并注册（[后端实现.md](后端实现.md)）。
3. `src/types.ts` 加类型；`src/lib/ipc.ts` 加方法。
4. 在 store 或组件中调用，保持「先持久化、后更新内存」。
5. 更新 [版本记录.md](版本记录.md)。

### 8.2 新增一个对话框

1. 在 `useLibrary` 加 `openX/closeX` 与开关字段（若属于全局）。
2. 用 `Modal` 包裹，遵循 [界面与交互.md](界面与交互.md) 的间距与焦点规则。
3. 若涉及异步，创建独立 store 工厂并用生命周期/请求版本丢弃迟到响应。
4. 在 `App` 中按开关挂载；注意 `key` 与卸载清理。

### 8.3 新增一个字段

1. [数据模型.md](数据模型.md) 写字段、默认值、写入者。
2. Rust `models.rs` 加 `#[serde(default)]`；`src/types.ts` 与 `newGameDraft()` 同步。
3. 表单、详情、导入导出按需接入；不必改无关组件。
4. 补迁移说明与测试。

### 8.4 新增视图规则

先改 `lib/library.ts` 的纯函数与测试，再让 `useLibraryView` 消费；不要在组件里复制过滤/排序逻辑。
