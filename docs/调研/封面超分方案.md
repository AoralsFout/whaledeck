# 封面超分选型依据

取证日期：2026-10-22；效率与质量档已接入。本文保留实际采用方案的选型依据和来源，删除未采用的模型路线及已被实现取代的操作提案。当前行为以[后端实现](../后端实现.md) §8.5、[接口契约](../接口契约.md) §2.10、[数据模型](../数据模型.md)和[界面与交互](../界面与交互.md)为准；测试与交付记录见[版本记录](../版本记录.md)。

## 已采用的模型与执行方式

| 档位 | 模型 | 采用依据 |
|---|---|---|
| 效率 | Real-CUGAN `up2x-conservative` 2× | 保守增强路线，用于控制处理成本；最终参数见后端规范。 |
| 质量 | Real-ESRGAN anime6B | 面向动漫图片与插画的模型；实际画质与耗时记录见版本记录，不推广为所有素材的通用排名。 |

用户手动选择封面与档位。采用独立 ncnn 辅助进程按任务处理，处理结束释放资源，平时读取保存的增强结果。这符合不在切换游戏、打开页面时启动推理的需求，也避免在应用中引入 Python / PyTorch 环境。

原图与派生图分离，缓存随源图内容与模型参数变化失效；任务调度、取消、进度适配及输出校验由后端负责。这里保留设计原因，具体流程只在上述权威文档维护。

## 适用边界

- 模型输出更多像素不等于恢复真实细节，也不会补回显示裁切丢失的构图；二次元模型不保证适用于照片、文字或像素画。
- 模型大小、倍率和处理时长不能单独作为画质依据；单机封面样本不能代表所有设备与素材。
- 现成工具的分块输出不等于完整任务进度，不能只靠退出码接受输出；当前适配与错误处理见后端实现。
- 程序、模型、ncnn 及第三方图像库的许可分别归档，实际随包文件与许可证见 `src-tauri/binaries/superres/`；不能用包装程序的 MIT 许可覆盖整条依赖链。
