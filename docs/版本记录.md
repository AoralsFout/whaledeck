## v0.8.1 — 2026-10-22

**主题**：窗口与详情底栏收尾、启动首帧优化。

- 版本号提升到 0.8.1，合并无边框窗口、详情底栏、UI/UX 流程三个分支。
- 新增无边框圆角窗口与悬浮控制键（最小化/最大化/关闭）；透明窗口四角不再出现黑底。

- 启动时窗口保持隐藏，等游戏库、图片解码、字体就绪并经过两帧后再 `show()` + 聚焦，避免白屏/闪烁。
- 修复 Vite 监听 Rust 构建目录导致的 EBUSY（`watch.ignored: **/src-tauri/**`）。
- 验证：`pnpm build`、`pnpm test`、`cargo test` 通过；实机启动无闪烁。
- 相关：[系统架构.md](系统架构.md) §5.1、[界面与交互.md](界面与交互.md) §2。

## v0.8 — 2026-10-22

**主题**：图像分层 + 底部启动栏 + UI/UX 细节。

- `Game` 拆分 `coverFile`（横版封面）与 `iconFile`（列表图标）；主区背景只用封面，侧栏优先图标。
- 自动补全改为：版本资源 → 名称/开发商/备注；系统图标写入 `icons/`；本地封面有则更新、无则保持原封面。不再把 exe 图标当封面。
- 联网检索无结果时，弹窗内提供「手动选择封面」。
- 启动栏与时长统计固定到主区底部；按钮统一 hover 上浮、active 缩放、图标微放大。
- UI/UX 批次：
  - 筛选/搜索/排序与当前详情共用视图规则；无结果提供清除筛选空态。
  - 详情保留悬停渐显，并增加可点击、键盘可操作的展开入口。
  - ≤700px 侧栏变为覆盖层导航；窄屏/矮窗口下底栏、表单、弹窗可重排滚动。
  - 弹窗统一语义、Tab 焦点约束、Escape、遮罩关闭与焦点返回；尊重减少动态效果。
  - 设置页分「外观/分类/数据/关于」标签页，支持方向键切换。
  - 操作栏统一提示：首次 1000ms、探索期 600ms、键盘聚焦立即显示。
  - 弹窗遮罩关闭必须由同一次主指针在外部按下并抬起触发；内部拖选不关闭。
- 写入与批量加入批次：
  - 单项保存/收藏/扫描加入共用「后端返回记录 → 更新列表」规则，不重载整库。
  - 批量顺序执行，成功即时入库，首个失败即停；失败提示含已加入/剩余数量；重试按路径去重（大小写与分隔符不敏感）。
  - 后端单项保存先写盘、成功后再替换内存。
- 请求生命周期批次：
  - 联网检索用请求版本号隔离乱序响应；切换来源/关闭弹窗使旧请求失效。
  - 存档备份按详情生命周期隔离；列表只接受最新读取，备份成功先接纳记录再刷新。
- 验证：覆盖首项/中途失败、即时更新、重试去重、并发批次、空批次、写盘失败回滚、乱序响应与生命周期重入。
- 相关：[数据模型.md](数据模型.md) §2.1、[前端实现.md](前端实现.md) §2、[后端实现.md](后端实现.md) §8、[界面与交互.md](界面与交互.md)。

## v0.7 — 2026-10-22

**主题**：隐藏式详情 + 通用自动补全。

- 主区常显标题、开始按钮、统计栏；简介/程序信息/存档备份/备注默认隐藏，hover 详情区淡入。
- 新增 `autofill(gameId)`：
  - 读取 exe 版本资源（`ProductName` / `CompanyName` / `FileDescription` / `FileVersion`）。
  - 本地封面扫描；找不到时回退系统图标（恢复 v0.5 关闭的图标兜底，仅作最后手段）。
  - 前端「自动封面」按钮改为「自动补全」，提示实际来源。
- 决策：普通软件（QQ、浏览器等）没有稳定公开信息 API，因此自动补全全部本地完成，不联网。
- 相关：[后端实现.md](后端实现.md) §8。

## v0.4 — 2026-10-22

**主题**：自动封面（三层兜底）。

- `find_local_cover`：在目标目录、常见图片子目录、必要时上一级/上两级目录中按文件名评分选图。
- `shell_icon_png`：`SHGetFileInfoW` → `GetIconInfo` → `GetDIBits` → RGBA → PNG。
- 接口 `auto_cover(gameId)`；详情页新增按钮。
- 限制：系统图标约 32–48px，放大偏糊；不解析 exe 内 256px 图标，不读 Steam `librarycache`。
- 验证：新增封面命名优先级、子目录、小图/非图忽略、系统图标、缺失路径测试；产出 0.4.0 安装包。
- 相关：[后端实现.md](后端实现.md) §8。

## v0.3 — 2026-10-22

**主题**：联网补全。

- 接入三家公开接口：Bangumi（`POST /v0/search/subjects`，type=4）、VNDB（`POST /kana/vn`）、月幕（OAuth2 client_credentials + `search-game`）。
- 不接入鲲（无公开 API，避免逆向站内接口）。
- 应用内容：封面下载、简介、开发商、发售日期、来源与来源 ID；外部图片只允许三家图床，单张 ≤12MB。
- 新增 `source/sourceId/developer/releaseDate/summary` 字段；旧数据用 serde 默认值兼容。
- 合规：非商业使用；月幕在 README 署名；不做批量/定时抓取。
- 验证：三家实测搜 CLANNAD 均有结果；Rust 测试通过；提供 `#[ignore]` 联网冒烟。
- 相关：[后端实现.md](后端实现.md) §9、[产品定义.md](产品定义.md) §6。

## v0.2 — 2026-10-22

**主题**：任意目标 + 文件夹扫描 + 存档备份。

- 不再限定 `.exe`：快捷方式、bat/cmd、文档、图片、文件夹都可加入；按扩展名决定进程启动或 Shell 打开。
- 新增 `scan_folder`（当时限制：最多 6 层、500 个结果，跳过系统/依赖目录）。
- 新增 `savePaths` 与存档备份命令；备份为 zip，内含 `manifest.json` 与按目录序号前缀的文件。
- 数据模型加 `Game.savePaths`（`#[serde(default)]`）；新增 6 个 IPC 命令。
- 安装排障：NSIS 沿用注册表旧 `InstallLocation` 导致无写权限；处理方式写入 README，并提供便携版。
- 验证：存档备份/还原往返、路径穿越拒绝、备份列表、启动类型判断测试；产出 0.2.0 安装包。
- 相关：[数据模型.md](数据模型.md) §4.5、[后端实现.md](后端实现.md) §10、[README](../README.md)。
